# ATM Interface

## Project Overview
This project simulates basic ATM banking operations using Java.  
Users can perform activities such as balance checking, cash withdrawal, money deposit, and transaction viewing.  
The system is designed to provide a simple and interactive banking experience.  
This project helped in understanding real-world application flow using Java concepts.  

## Features
- Balance Inquiry  
- Cash Withdrawal  
- Money Deposit  
- Transaction Details  
- User Authentication  

## Technologies Used
- Java  
- OOP Concepts  
- Loops & Conditional Statements  

## Purpose
This project was developed to improve Java programming skills and understand banking system operations.
