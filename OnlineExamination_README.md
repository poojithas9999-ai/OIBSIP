# Online Examination System

## Project Overview
The Online Examination System is a Java-based application developed for conducting online tests digitally.  
Users can answer multiple-choice questions and submit their responses within the system.  
The application automatically evaluates answers and displays the final result.  
This project improved logical thinking and application development skills in Java.  

## Features
- Multiple Choice Questions  
- Automatic Result Calculation  
- User-Friendly Interface  
- Question Navigation  
- Exam Submission System  

## Technologies Used
- Java  
- Arrays & Loops  
- OOP Concepts  
- Conditional Statements  

## Purpose
This project was developed to gain practical experience in Java programming and understand online examination workflows.
